# বাজার দর (Bajar Dor)

** About the Project **

Bajar Dor is a web application that helps users check the prices of daily essential products easily. Users can explore product prices, compare price changes, and view market information.

** Features **

- View daily product prices.
- Browse products by category.
- Compare today's prices with previous prices.
- View products with increased or decreased prices.
- Search and sort products.
- User registration and login with email and password.
- Responsive design for mobile, tablet, and desktop.

** Technologies Used **

- Next.js
- React
- Tailwind CSS
- Better Auth
- MongoDB
- REST API
- Vercel
